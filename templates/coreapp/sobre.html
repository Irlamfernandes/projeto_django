Sobre o Projeto

O BuscarFilmes é um projeto acadêmico desenvolvido com o objetivo de ajudar usuários a encontrar filmes, informações detalhadas e onde assistir online.

Nosso foco é proporcionar uma experiência simples e intuitiva para quem deseja descobrir novos filmes e acompanhar os mais populares.

Créditos

Este projeto foi desenvolvido como parte de uma atividade acadêmica para estudo de desenvolvimento web com Django.
